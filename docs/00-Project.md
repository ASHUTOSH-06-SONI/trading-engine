# Trading Engine

## What are we building, and why?

I want to rebuild my existing trading engine from scratch in C++ because the original was heavily vibe-coded, and I don't fully like how it turned out.

The idea is to experiment with low-latency trading, order books, market microstructure, and simple strategies in crypto markets.

Obviously, we're not beating HFT firms with a MacBook M1 lmao. But we can still learn a lot about performance engineering and investigate whether faster processing and better signals can give us an edge.

I'll be using this paper heavily: https://arxiv.org/pdf/2309.04259

This is a side project. I'll document things as I build, push it to GitHub eventually, and try not to vibe-code my way through it again.
